Load the macro on the MTR device

  1. Click Download macro above to save the complete macro, or click Copy config if you would rather paste only the config into an existing copy of main.js.
  2. Open the Macro Editor, either on the device's web interface (Customization › Macro Editor) or in Control Hub (Devices › select the device › Macros).
  3. To use the downloaded file, choose Import from file and select it, or create a new macro and paste its contents. To use only the config, open your existing macro and replace everything between the // CONFIG:start and // CONFIG:end markers with the copied block.
  4. Save the macro, then click its Activate toggle so it turns blue. A blue toggle means the macro is activated and running; if it is grey, the macro will not run.
  5. Optional: to host the web app on your own server, continue to the Export Web App tab.

Export Web App

By default the macro points the Room Navigator at the copy of the web app hosted on GitHub Pages. To host your own copy, for example on an internal web server the Navigator can reach, download the bundle below. It is a static site: the web app, its scripts and its icon, with the same CDN links for jsxapi and the Momentum icons and theme.

Optional. This is the same value as the Web app URL on the General tab, so the macro you export points at your server.

Example: hosting on Microsoft IIS

  1. An admin downloads the bundle here and unzips it into a folder on the IIS server, for example C:\inetpub\wwwroot\mtr-controller-pwa.
  2. In IIS Manager, add a website (or a virtual directory or application under an existing site) whose physical path is that folder, with an HTTPS binding the Room Navigator trusts.
  3. Browse to the site. Seeing "No parameters found in the URL hash" is correct: the macro supplies the parameters. There is no server side code to configure.
  4. Enter the site's URL as the Web app URL (above, or on the General tab), then export the macro again and load it on the MTR device.

From then on the macro keeps updating the URL hash on your server's address, with the account, device IP address, mode and calendar setting, exactly as it does for the GitHub Pages copy. The bundle still loads jsxapi and the Momentum icons from public CDNs; on a network without internet access, host those too and update the links at the top of index.html.
